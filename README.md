# 📖 YazarKitap — Katmanlı Mimari (C#)

Yazar ve kitap kayıtlarını yöneten, **katmanlı mimari** (N-Tier) ile geliştirilmiş C# uygulaması.

## Katmanlar
- **Entity** — veri modelleri
- **BLL** — iş mantığı katmanı (Business Logic Layer)
- **Facade** — katmanlar arası cephe
- **Presentation** — sunum katmanı

## Teknolojiler
C# · .NET · Katmanlı Mimari · SQL (`yazarkitap.session.sql`)
